# Try Instant Fit — Video 01 Production Package

## Objective

Create a fast, premium 12–15 second vertical Instagram Reel for fashion vendors:
boutiques, clothing brands, bridal studios, designers, suit stores, and online retailers.

Core message: customers can see an outfit on themselves before they buy.

## Google Flow / Gemini Omni Flash settings

- Output: vertical 9:16
- Resolution: highest available; final export target 1080 × 1920
- Frame rate: 30 fps
- Generate the two transformation clips separately
- Use the supplied start and end images as references/frames
- Do not ask the model to recreate phone UI or readable text
- Assemble the real phone frames after the generated transformations

Google recommends clean reference subjects on plain backgrounds. These supplied images
already use a clean white background.

## Clip order

1. `01-clip-everyday-to-formal` — 4 seconds
2. `02-clip-everyday-to-wedding` — 4 seconds
3. `03-real-phone-flow` — compress selected frames into 3–4 seconds
4. `04-brand/logo.png` — 2-second final card

Recommended final duration: 14 seconds.

## Critical privacy rule

Every face must remain strongly blurred in every frame, including generated transitions,
phone screens, try-on results, reflections, thumbnails, and the cover image. The blur
must never disappear, sharpen, or reveal facial features for even one frame.

After export, inspect the video frame by frame. Apply a second tracked blur in an editor
if the generated video weakens the existing blur.

## Real phone-frame sequence

Use these in numeric order:

`flow-1.jpg` → `flow-2.jpg` → ... → `flow-11.jpg`

Show each for approximately 0.25–0.35 seconds using quick cross-fades. Do not regenerate
these screens with AI because the real interface and text must stay accurate.

## On-screen text

- Opening: `Customers unsure about the outfit?`
- Transformation: `Let them try it instantly.`
- Phone flow: `One photo. See the look.`
- Final card: `Own a fashion brand?`
- CTA: `DM “DEMO”`

Keep text inside the center-safe area so Instagram interface elements do not cover it.

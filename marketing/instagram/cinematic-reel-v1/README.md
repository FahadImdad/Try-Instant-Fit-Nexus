# Cinematic Reel V1

This is the complete 18-frame production sequence for the vendor-focused Reel “Try It Here. Try It Anywhere.”

- Upload the PNG files from `frames` in numerical order.
- Paste `VIDEO-PROMPT.md` into the video generator.
- Generate at 9:16, 24 seconds and 30 fps.
- Reject any output that reveals a face, changes a garment, rewrites the UI or invents a scene.

The reference photographs supplied by the client were used only to understand body diversity, garment categories, privacy treatment and the product flow. The cinematic frames are newly created scenes.

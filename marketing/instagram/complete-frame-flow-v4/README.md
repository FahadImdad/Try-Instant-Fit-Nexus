# Try Instant Fit — Complete Instagram Reel Flow

This package contains twelve finished 1080 × 1920 frames for one 14-second vendor-focused Instagram Reel.

## Upload to Google Omni

1. Upload every PNG from the `frames` folder.
2. Keep the files in numerical order from `01-hook.png` through `12-cta.png`.
3. Paste the complete contents of `GOOGLE-OMNI-PROMPT.txt`.
4. Select vertical 9:16, 1080 × 1920, 14 seconds, and 30 fps when those controls are available.
5. Reject any generation that reveals or reconstructs a face, changes the UI, misspells text, or modifies a garment.

## Campaign logic

- Frames 01–02: consumer problem and instant visual promise.
- Frames 03–09: authentic product flow and proof.
- Frames 10–11: Pakistani wedding-wear use case.
- Frame 12: vendor conversion CTA.

## Privacy

Every visible face, including faces repeated inside phone screens, is deliberately obscured. The animation prompt requires the video model to preserve that treatment for every frame.
